Turn the request into a plan. Do not edit files and do not start an implementation.

Cover:

1. Which existing block is the closest pattern, and what new block name you would use.
2. Authored cells, keyboard behavior, alt text, contrast, and reduced motion.
3. The check that proves it: `npm run lint` and `npm test`.
4. Decisions a person must make before anyone writes code.
5. Which model should implement it, and why, using `.cursor/rules/model-policy.mdc`.
